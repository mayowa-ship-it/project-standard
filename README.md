# Project Standard

A panel for Adobe Premiere Pro and After Effects (2024 or newer, Mac and Windows) that sets up, organizes, names, collects and delivers every project the same way.

## Install

1. Download `ProjectStandard-<version>-install.zip` from the [newest release](https://github.com/mayowa-ship-it/project-standard/releases/latest).
2. Unzip it and follow `How to install.txt`: drag the `.zxp` into the free [ZXP Installer](https://aescripts.com/zxp-installer/).
3. In Premiere Pro or After Effects: Window > Extensions > Project Standard.

After that the panel updates itself: a blue "Update available" bar appears when a new release is published here.

This repository holds releases only.
